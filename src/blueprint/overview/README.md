# Overview

This chapter is the Blueprint's front matter. It fixes what the boundary must provide, states the idea in one page, defines the vocabulary the rest of the volume uses, and names the challenges the design answers. A reader who stops at the end of it should know what a kernelet and the endovisor are, what makes API virtualization hard, and where in the Blueprint each mechanism is built.
